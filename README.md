# Дашборд

Тестовый frontend-проект для управления каталогом товаров и просмотра истории покупок.

## Реализовано

- авторизация по тестовым данным;
- защищённые страницы каталога и истории покупок;
- добавление, редактирование и удаление товаров;
- валидация форм и подтверждение удаления;
- первоначальные данные товаров и покупок;
- сохранение авторизации и изменений каталога в `localStorage`;
- отображение истории покупок с суммами, включающими НДС;
- адаптивный интерфейс для компьютеров, планшетов и телефонов.

## Дополнительные решения

- Angular 22 и standalone-компоненты;
- Signals и вычисляемое состояние через `computed`;
- `ChangeDetectionStrategy.OnPush` во всех компонентах;
- ленивая загрузка страниц через Angular Router;
- функциональные `authGuard` и `guestGuard`;
- Reactive Forms с типизированными контролами;
- новый синтаксис шаблонов `@if`, `@for` и `@empty`;
- View Transitions при переходах между страницами;
- Taiga UI 5 для форм, кнопок, таблиц, диалогов, уведомлений, бейджей, аватара и иконок;
- цвета, типографика, состояния и тени на основе дизайн-токенов Taiga UI;
- БЭМ-именование собственных CSS-классов;
- отдельные сервисы для авторизации, товаров, истории покупок и работы с `localStorage`;
- единая константа `DEFAULT_VAT_RATE` для ставки НДС 22%;
- автоматическая миграция ранее сохранённых данных со ставки НДС 20% на 22%.

## Запуск

Требуется Node.js `22.22.3+`, `24.15.0+` или `26+`.

```bash
npm install
npm start
```

Открыть `http://localhost:4200`.

Тестовый пользователь: `test` / `Test1234`.

## Проверка production-сборки

```bash
npm run build
```
